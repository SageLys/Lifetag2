# WRITING_GUIDE.md — 人生标签交易所：试用期

---

## 一、两套声音，永不混用

**Shell 声音**（标签名、流向按钮、吉祥物台词）：商业的，欢快的，热情过头一点。

**Core 声音**（档案摘要、底细、即时反馈、回单）：制度的，精确的，不解释，不安慰，不评价。

同一个字段只用一种声音。

---

## 二、Core 声音规则

**句法：**
- 一句话一个事实，句间无因果
- 省略不必要的主语
- 动词直接跟结果

**禁用词类：**

| 类型 | 禁用示例 |
|------|---------|
| 情绪程度词 | 很、非常、极其、令人、可惜 |
| 因果连词 | 因此、所以、由于、导致 |
| 主观评价 | 优秀、糟糕、聪明、可悲 |
| 安慰/展望 | 希望、未来、机会、努力 |

**正误对照：**

```
✓ "三段实习都只持续两周。"
✗ "由于缺乏职场经验，他的实习表现令人担忧。"

✓ "背调发现履历注水，本次出货失误。"
✗ "很遗憾，这次出货未能成功，下次请多加注意。"

✓ "买家完成签单，本次出货成立。"
✗ "太好了！买家接受了这个案件，出货成功！"
```

## 三、各字段写法

### 档案摘要（summary）
上限 25 字。玩家第一眼看到的信息。写最突出的表面特征，不写判断。

```
✓ "知名院校应届生，实习经历完整，标签组合标准。"
✓ "中年男性，稳定收入，家庭背景可解释，情绪记录存疑。"
✗ "这是一个表面光鲜但实则问题多多的案件。"
```

### 底细（lore）
2-4 句。扒底后显示。外部观察者视角，描述可观察事实，让玩家自行推断底标。不写"他/她"，不写内心，不点破。

最好包含一句看似无关但关键的细节。

```
✓ "三段实习都只持续两周。推荐信的语气和模板库高度相似。"
✓ "在三家公司的劳动仲裁记录均为胜诉。上一任雇主拒绝接听电话。"
✓ "账号注销三次。每次注销前都有一段集中发帖期。"
✗ "她内心深处渴望被认可，但多次的失败已经让她伤痕累累。"
```

### 即时反馈（feedback）
上限 20 字。出货后立即显示。格式：买家行动 + 简短状态。

```
✓ "买家已接收档案，要求进入背调。"
✓ "流量池标记该案卷为'可发酵'。"
✓ "家长审核中，关注点转移至学历背景。"
✗ "案件已成功投递，请等待结果。"
```

### 买家回单（receipt）
上限 60 字。结果陈述，末尾附结算。不解释为什么。

```
✓ "背调发现履历注水，本次出货失误。"
✓ "发酵至第三天触发平台审核，已限流。出货成立，交易所不承担后续叙事责任。"
✗ "由于候选人的履历存在问题，导致背调不通过，因此判定为失误。"
```

### 长期回响（longEcho，可选）
上限 40 字。后续班次出现的尾声，可以是好消息也可以是坏消息。交易所对此不负责。

```
✓ "B-09 三天后被平台限流。交易所备注：已完成结算，不承担后续叙事责任。"
✓ "C-04 在婚恋流向发酵为'被门当户对抛弃的体面人'，播放量持续攀升。"
```

## 四、Shell 声音规则

### 标签命名
2-5 字，名词形式，描述属性，不作判断。

```
✓ 维权意识强 / 35+ / 争议感 / 脆皮 / 过早觉醒
✗ 爱闹事的 / 年纪大了 / 能红 / 身体不好
```

### 流向按钮副文字
机构语气，正面，不超过 8 字。

```
✓ "本日接收中" / "配额充裕" / "优先通道开放"
✓ "本日暂停接收"（不可用状态）
```

### 吉祥物标宝台词
企业宣传口吻，内容实为制度告知，可用感叹号（仅此处允许）。

```
✓ "感谢您为人生流通作出贡献！"
✓ "押金标签尚余 N 枚，请注意操盘质量。"
✓ "本交易所不承担出货后的叙事责任。"
```

## 五、整体语气校验

写完一条文本后，用以下标准自查：

- 能不能去掉这个形容词？去掉后意思没变 → 去掉
- 这句话在解释原因吗？在 → 删掉原因，只留结果
- 这句话在评价人吗？在 → 改成描述行为或结果
- 这句话带情绪吗？带 → 换成中性动词
