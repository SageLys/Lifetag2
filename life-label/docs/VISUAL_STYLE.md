# VISUAL_STYLE.md — 人生标签交易所：试用期

*给 Claude Code 的视觉风格规格文档。所有布局分区、交互行为和动画另见 UI_SPEC.md。本文档定义颜色、字体、视觉元素样式和风格层级规则。*

---

## 1. 设计定位

### 1.1 核心概念：彩色消费主义荒诞风

**交易所对外形象**是热闹繁荣的"人生百货商场"：彩色促销价签、买家专区导视牌、实时跳动的 LED 行情屏、永远面带笑容的官方吉祥物。整体色彩明亮、商业气息浓厚，表面上像一个正常的零售批发环境。

**案件处理的实质**在文本层揭示：档案摘要、底细、买家回单、押金扣除通知使用冷酷的制度化语气，语言精确，没有情感，没有安慰，没有解释。

这两层构成游戏的核心视觉反差。参见 §5 对这一规则的完整规定。

### 1.2 参考感受（非参考复制）

以下是用于校准整体视觉感受的参照，不应直接复制其视觉元素：

- 中国 90 年代大型百货商场的楼层导视系统
- 日本超市和便利店的手写促销价签
- 日本自动贩卖机界面（信息密度高，彩色，清晰）
- 出口创汇时代的产品出口标签和检验章

### 1.3 明确禁止的方向

- **禁止"血腥肉铺"**：不使用深红暗红配大量黑色，不使用恐怖、内脏、残酷的视觉元素
- **禁止"灰暗官僚办公室"**：不使用大面积灰色、黑色、低饱和度单色调配色
- **禁止"无害可爱经营游戏"**：不使用 pastel 色系（粉蓝粉紫蜜桃低饱和可爱色），不使用圆润装饰图案，不使用软萌卡通风格

## 4. UI 元素视觉参考形象

以下为每个主要 UI 元素的视觉参考形象，用于校准实现风格。这些描述面向实现者，说明元素应"像什么东西"：

**案件卡：** 像超市或百货公司货架上的"商品陈列说明牌"——贴在展示台边缘的白卡，顶部有品牌色横条，内容结构清晰，整洁但偏商业感，不像个人简历也不像网页卡片。

**标签挂牌：** 像实体商品上的吊牌（带圆孔的小纸卡）。多枚挂牌聚集展示，像一组商品标签贴在案件卡上。底标的"?"挂牌像一张正面朝下的价签，揭开前不知道上面写什么。

**流向按钮：** 像商场分区导视牌——有颜色的大标牌，上面写着区域名称和当前状态。每个流向是一个"专区"，像大厂专区、创业孵化区、婚恋配对区、流量变现区。

**操作按钮（扒底/揭标/退货）：** 像收银台边的功能按键，或工具箱里的实体按钮——不是号召行动的大按钮，是工具性的小按键。颜色不突出，融入台面。

**买家回单：** 像热敏打印机打出的超市小票，或印在薄纸上的公文电报——字小、密排、无装饰，内容是事实陈述。

**押金标签图标：** 像积分卡上的印章格子，或通行证上的孔位——存在时是实心的，扣除后变成带叉的空格。

**LED 行情屏：** 像股票交易所或旧式机场的滚动报价屏——黑底、绿红数字、等宽字，嵌在商场暖调 Header 里形成反差。

## 5. Shell 与 Core 的视觉分界规则

这是本游戏最重要的设计原则，必须严格执行。

**Shell 层（游戏外壳）：** 全部 UI 框架、导视元素、标签挂牌形状、流向按钮、押金图标、吉祥物、行情屏框架。视觉语言：彩色、商业、温暖、略带荒诞感。

**Core 层（案件内核）：** 案件档案摘要文字、底细文字、买家回单正文、押金扣除通知正文、操作倾向档案内容。视觉语言：单色、密排、制度化、无装饰。

### 5.1 Shell 层专属规则（Core 层禁止使用）

- 多颜色配色（标签语义色、流向品牌色）
- ZCOOL KuaiLe 字体
- `border-radius > 8px`（高圆角）
- 任何装饰性图形（吉祥物、图标、背景纹理）
- `box-shadow`

### 5.2 Core 层专属规则（Shell 层禁止使用）

- 极小字号（11px）+ 密排行高（1.7–1.8）组合
- 等宽字体（Space Mono）用于连续叙述性文字
- `border: 1px dashed` 虚线边框
- 纯黑 `#1A1A1A` 作为正文颜色（Shell 层按钮文字允许用白色，不允许用纯黑）

### 5.3 交界区规则（案件卡）

案件卡是两层交界最明显的地方，须明确划分内部层级：

| 区域 | 所属层 | 视觉规则 |
|------|--------|---------|
| 卡片顶部红条（含品牌小字） | Shell | 品牌红背景、白字、ZCOOL KuaiLe |
| 案件名称 | Shell/Core 过渡 | Noto Sans SC Bold，黑色，无装饰 |
| 档案摘要文字 | Core | Noto Sans SC Regular，小号，灰色 |
| 标签挂牌（正面标签） | Shell | 彩色边框、白底、吊牌形状 |
| 底标挂牌（揭示前） | Shell | 灰色吊牌形状，"?" |
| 底标挂牌（揭示后） | Shell/Core 混合 | 风险红背景吊牌 + 制度化文字 |
| 底细文字区 | Core（偏软） | Ma Shan Zheng 斜体，暖棕色，无边框装饰 |

## 6. 吉祥物"标宝"视觉规范

### 6.1 形态定义（SVG 实现）

标宝是人生标签交易所的官方吉祥物，必须用 SVG 代码实现，不使用图片文件。

外形由以下基础几何元素组成：

- **身体**：圆角矩形，约 32px 宽 × 40px 高，`rx=6`，填充品牌红 `#D32F2F`，细白色边框（`stroke: white; stroke-width: 1`）
- **顶孔**：身体顶部居中，一个圆形（直径 6px），用与 Header 背景相同颜色填充（形成镂空感，模拟价签挂孔）
- **面部**：
  - 眼睛：两个实心白色圆形，直径 5px，左右对称，位于身体中上部
  - 嘴巴：上扬弧线，`stroke: white; fill: none; stroke-width: 1.5`，曲率略大于"正常微笑"（这个细节制造轻微的不安感）
- **手臂**：两侧各一条直线（`stroke: white; stroke-width: 1.5; stroke-linecap: round`），长约 12px，向外斜下延伸，端点处一个小圆（2px 白色实心）
- **腿部**：身体底部两条短线，各向外斜下约 10px，端点小圆（2px 白色实心）
- **胸牌文字**：身体正中，"标宝"二字，ZCOOL KuaiLe 8px 白色，居中

### 6.2 尺寸变体

| 场景 | 尺寸 | 说明 |
|------|------|------|
| Header 品牌区（常规显示） | 约 36px 高 | 与品牌文字并排 |
| 空工作台占位（无选中案件） | 约 64px 高 | 居中显示，下方配提示语 |
| 结局画面 | 约 80px 高 | 姿态变体（见下） |

### 6.3 姿态变体（CSS transform 实现）

| 场景 | 姿态 | 实现方式 |
|------|------|---------|
| 正常状态 | 直立，微笑 | 无变换 |
| 玩家操作出色时 | 举手（左臂上扬） | 左手臂 SVG path 修改 |
| 押金归零/失败结局 | 低头 | `transform: rotate(15deg)` 轻微倾斜 |
| 空闲等待 | 轻微摇摆 | CSS `@keyframes` 左右 `rotate(±3deg)`，3s 循环 |

### 6.4 标宝语录（偶发 tooltip 气泡）

气泡形状：圆角矩形（`rx=4`），白底，细灰色边框，底部有三角指针朝向标宝。

气泡文字使用 ZCOOL KuaiLe 12px，内容为企业宣传口吻 + 实为制度告知的内容：

- "感谢您为人生流通作出贡献！"
- "今日行情波动，请做好心理准备。"
- `押金标签尚余 N 枚，请注意操盘质量。`（动态插入数值）
- "本交易所不承担出货后的叙事责任。"
- "每一个案件，都是宝贵的流通资源。"

出现时机：每班开始时显示一次，可点击关闭；押金剩余 2 枚时自动出现一次。

## 7. 视觉禁止项

### 颜色禁止

- 禁止纯白 `#FFFFFF` 用于任何可见容器或区域背景
- 禁止大面积深色 `#333333` 以下的颜色用于主背景或主要区域
- 禁止渐变（`gradient`）用于任何 UI 背景或容器（允许在 LED 屏边缘做 1px 渐变模拟屏幕边框）
- 禁止 pastel 低饱和度可爱色系（粉蓝 `#B3E5FC`、薰衣草 `#EDE7F6`、蜜桃 `#FCE4EC` 等用作主色）
- 禁止随机分配标签颜色（必须严格按 §2.3 语义分类）

### 字体禁止

- 禁止使用系统默认字体（所有文字必须使用加载的四种 Google Fonts 之一）
- 禁止 Ma Shan Zheng 用于底细信息以外的场景
- 禁止 ZCOOL KuaiLe 用于 Core 层文字（买家回单、押金扣除通知、档案摘要正文）
- 禁止 Space Mono 用于连续段落正文（仅用于数据字段和编号）

### 效果禁止

- 禁止 `blur()` `drop-shadow()` 视觉模糊或光晕效果
- 禁止多重 `box-shadow` 叠加（整个游戏最多在案件卡展开态使用一处 `box-shadow`）
- 禁止 `border-radius > 12px`（避免过度圆润的可爱感）
- 禁止任何 emoji 字符用于游戏正式 UI（允许在标宝话语中使用）
- 禁止背景图案、纹理图案（`background-image`）用于任何主要区域

### 风格禁止

- 禁止纯灰暗色系作为整体基调（禁止"Paper Please 克隆"的全程压抑灰调）
- 禁止将 Core 层内容（回单、押金扣除）用彩色装饰框或彩色背景包裹
- 禁止将 Shell 层按钮（流向按钮、操作按钮）用制度化灰黑色处理
